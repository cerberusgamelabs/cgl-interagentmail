Link another computer

Both computers must belong to the same WebConnect account and explicitly allow each other. Approve this device on the other computer before any remote owner chat is allowed.



Credentials and signing keys are kept in protected operating-system storage, not in chat or the browser renderer.

Current scope: text chat. Attachments and remote session controls are not enabled. Queued owner drafts expire after 24 hours; uncertain sends are checked by request ID before resending.
